# CalorieK v0.0.5 发布候选

CalorieK 是一款本地离线的体重与热量记录应用，以日 K 线展示实际体重，并结合饮食、运动、基础消耗进行预测和校准。

## 下载

v0.0.5 候选源码待 Windows 发布验收。已发布的 Windows x64 ZIP 见 [v0.0.4 下载页](https://github.com/AtticusPhu/CalorieK/releases/tag/v0.0.4)。

下载 Windows ZIP，完整解压后运行 `CalorieK.exe`，保留同级依赖目录。无需安装 Python。

## 主要功能

- 体重、饮食、运动历史记录及修正
- 食品、食谱、每日营养与能量汇总
- 体重 K 线、能量 Treemap 和个人模型校准
- kJ/kcal 单位切换、SQLite 本地存储、ZIP 备份恢复和 JSON 导出

### v0.0.5 候选版的日期校验与记录恢复

饮食、运动和称重按录入时间自身的本地日历日判断。可以录入今天稍晚的记录，从明天起不能新增实际记录。饮食和运动需要当日已有生效的资料，并且当日或更早至少有一次有效称重。

已有未来记录可以在首页“每日营养构成”选中原日期，点击“查看当日记录”打开并更正。可在原日编辑，也可改到符合上述条件的今天或过去日期。移动首个称重时，已有饮食和运动仍须由同日或更早的称重覆盖。

在当日时间线点击“删除”并确认，记录会退出统计，原行标记为“已删除”。点击该行的“恢复”并确认，可按原时间和数值重新计入统计。如果删除称重会让已有饮食或运动失去锚点，界面会提示需要称重的日期。即使删除最后一条称重后 K 线已清空，仍可通过“查看当日记录”回到原日期恢复。

新增、删除或恢复饮食、运动和称重记录时，若提交后图表重算失败，界面会说明记录已保存、已删除或已恢复。此时点击首页“刷新”即可重算，无需再次提交。

## 源码运行

源码运行环境为 Windows 10/11 x64、Python 3.14。

```powershell
python -m pip install -r requirements.txt
python main.py
```

源码入口为 `main.py`，应用代码、界面、计算模型、数据库结构及迁移均位于 `app/`。候选应用版本为 `0.0.5`，数据库 Schema 为 `3`，计算版本为 `v2-simple-energy-kj-1`。从 v0.0.4 升级沿用原有数据库和 kJ 计算模型。

源码运行默认数据目录为 `data/`；Windows 打包版默认为 `%LOCALAPPDATA%\CalorieK\data`。升级前请使用应用的 ZIP 备份功能。个人数据库、备份、导出、构建与测试产物不应提交到公开仓库。
